# NEXUS AI Local

一个可本地部署的网页应用：
- 支持多格式用户数据文件上传（TXT/MD/JSON/CSV/XLSX/DOCX/PDF）或直接输入文本。
- 在网页中直接填写 API 配置（Base URL、API Key、聊天模型、图像模型），无需外部配置文件。
- 使用自定义用户画像提示词生成核心用户画像。
- 基于「用户语义 -> 设计语义映射矩阵」自动提取功能语义与色彩语义。
- 自动补充联想句（如“产品有智能的控制面，整体颜色采用黑白”），拼接到用户画像后用于概念图生成。

## 一键部署启动

```bash
docker compose up --build
```

启动后访问：
- http://localhost:3000

## 本地开发启动

```bash
npm install
npm start
```

## 工作流

1. 上传多格式文件或直接输入文本。
2. 填写 API 参数（在页面中）。
3. 点击「重新生成」。
4. 后端顺序执行：
   - 用户画像生成
   - 语义映射匹配（功能语义 + 色彩语义）
   - 一句话补充
   - 概念图提示词生成
   - 图像生成
